# CSA-iLEM Archive_Data

This is the explicit local-only archive lane for CSA-iLEM material that is
extra, ambiguous, quarantined, or not yet proven to belong to a canonical
repository.

The native app must not silently place this material under Code/Repos. Each
payload should retain a receipt or decision note that identifies its source,
reason for routing, and next review action. Archive_Data is ignored except for
this README so personal project data is not committed with the application.

Raw directory preservation is preferred for canonical local backups. ZIP,
sparse-image, or other interchange media are optional artifacts and do not
replace the source or its evidence.
